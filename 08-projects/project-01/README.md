# Project 1 — Retail Sales Forecasting

## Objective

Build a forecasting model for monthly retail sales.

## Workflow

1. Obtain a dataset.
2. Clean the data.
3. Convert it to a tsibble.
4. Visualise the series.
5. Identify trend and seasonality.
6. Create a train/test split.
7. Fit naive and seasonal-naive models.
8. Fit an ETS model.
9. Fit an ARIMA model.
10. Compare accuracy.
11. Diagnose residuals.
12. Produce forecasts.
13. Write a short conclusion.

## Deliverables

- R script or Quarto notebook
- At least 3 models
- Accuracy comparison
- Forecast plot
- Short written interpretation
